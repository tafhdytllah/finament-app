# Functional Requirements

## Authentication

| ID          | Requirement |
|-------------|-------------|
| FR-AUTH-001 | Sistem harus memungkinkan pengguna membuat akun menggunakan fullname, email, dan password. |
| FR-AUTH-002 | Sistem harus memungkinkan pengguna melakukan login menggunakan email dan password. |
| FR-AUTH-003 | Sistem harus memungkinkan pengguna melakukan logout. |
| FR-AUTH-004 | Sistem harus memungkinkan pengguna memperbarui access token menggunakan refresh token. |
| FR-AUTH-005 | Sistem harus memungkinkan pengguna mengubah password. |

## User

| ID          | Requirement |
|-------------|-------------|
| FR-USER-001 | Sistem harus memungkinkan pengguna melihat informasi profilnya. |
| FR-USER-002 | Sistem harus memungkinkan pengguna memperbarui fullname. |
